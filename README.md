# Chameleon UI issue tracker

This is where to report bugs, request components and features, and point out documentation problems in Chameleon UI, the Material 3 Expressive component library for Web/JS, React, Blazor, Angular, Vue, and Svelte.

The Chameleon UI source is not public, so this repository holds only the issues and the forms that create them.

**[Open an issue](https://github.com/materia-technologies-inc/chameleon-issue-tracker/issues/new/choose)**

## Before you file

- **Search first.** Someone may already have reported it. Add your details to an existing issue rather than opening a new one.
- **Check the documentation.** [chameleonui.io](https://chameleonui.io) has every component's API and examples for all six frameworks.
- **Ask your agent.** The [Chameleon UI MCP server](https://github.com/materia-technologies-inc/chameleon-mcp) answers questions from the documentation and checks code against the API.

## What to file

| Form | Use it for |
| :--- | :--- |
| Bug report | A component that behaves differently from its documentation |
| Feature request | A new component, or a new option on an existing one |
| Documentation | A page that is missing, wrong, unclear, or out of date |
| Question | Something the documentation doesn't answer |

## What makes a good report

- **Framework:** Web/JS, React, Blazor, Angular, Vue, or Svelte
- **Chameleon UI version:** for example, 27.1
- **Component:** for example, `cw-button` or `CrSlider`
- **Browser and operating system**
- **A minimal reproduction:** the smallest code that shows the problem, ideally as a link to a StackBlitz, a CodePen, or a small repository

A report with a reproduction gets fixed first, because we can see the problem for ourselves.
