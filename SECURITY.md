# Security policy

Please don't report a security problem in a public issue.

Report it privately instead: on the [Security tab](https://github.com/materia-technologies-inc/chameleon-issue-tracker/security), choose **Report a vulnerability**. Only the Chameleon UI maintainers can see the report, and we'll reply there.

Include the Chameleon UI version, the framework, and the steps that show the problem.
